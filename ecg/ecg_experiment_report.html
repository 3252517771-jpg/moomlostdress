心电信号处理实验报告

1. 实验内容（题目）

设计并实现一个交互式心电信号处理系统，具备以下功能：

  • 对心电信号进行时频域显示、滤波处理和特征提取
  • 提供交互式界面，允许用户调整滤波器类型和参数
  • 实现心电信号的初步滤波处理，提取QRS波等关键特征

2. 实验原理

2.1 心电信号处理基础

心电信号（Electrocardiogram, ECG）是反映心脏电活动的生物电信号，包含P波、QRS波群和T波等特征波形。QRS波群是心电信号中最明显的特征，其检测对于心率计算和心脏疾病诊断具有重要意义。

2.2 滤波技术原理

  • 陷波滤波器（Notch Filter）：用于去除特定频率的干扰（如50Hz工频干扰），采用IIR结构，传递函数为：

    H(z) = (1 - 2cos(ω₀)z⁻¹ + z⁻²) / (1 - 2r cos(ω₀)z⁻¹ + r²z⁻²)

    其中ω₀为中心频率，r为阻尼系数。
  • IIR低通滤波器：采用Butterworth型，具有平坦的通带特性，阶数决定滤波效果和相位特性。
  • FIR低通滤波器：采用窗函数设计法（firwin），具有线性相位特性，阶数决定过渡带宽度。

2.3 QRS波检测原理

采用基于峰值检测的方法，通过设置合适的阈值和峰值间距参数，从滤波后的信号中识别QRS波群。检测步骤包括：

  1. 对信号进行低通滤波，增强QRS波特征
  2. 使用峰值检测算法识别候选峰
  3. 基于幅度和时间间隔筛选QRS波
  4. 计算RR间期和心率

2.4 时频域分析原理

  • 时域分析：直接观察信号的时域波形，分析波形特征和变化趋势。
  • 频域分析：使用快速傅里叶变换（FFT）将信号转换到频域，分析信号的频率成分和能量分布。

3. 实现代码及结果展示

3.1 系统整体架构

系统采用面向对象设计，主要包含以下模块：

  • 数据加载模块：负责从CSV文件读取心电信号数据
  • 滤波处理模块：实现陷波、IIR和FIR滤波器
  • 特征提取模块：检测QRS波和计算心率

  • 用户界面模块：提供交互式操作界面

3.2.1 系统主类设计

import numpy as np import scipy.signal as signal import matplotlib.pyplot as plt import pandas as pd import tkinter as tk from tkinter import filedialog class ECGProcessingSystem: def __init__(self, root): self.root = root self.root.title("心电信号处理系统") self.root.geometry("1200x800") # 初始化数据 self.ecg_data = None self.filtered_data = None self.fs = 500 # 采样频率 # 创建UI组件 self.create_ui() def create_ui(self): # 创建菜单栏 menubar = tk.Menu(self.root) self.root.config(menu=menubar) # 文件菜单 file_menu = tk.Menu(menubar, tearoff=0) menubar.add_cascade(label="文件", menu=file_menu) file_menu.add_command(label="加载数据", command=self.load_data) file_menu.add_separator() file_menu.add_command(label="退出", command=self.root.quit) # 主框架 main_frame = tk.Frame(self.root) main_frame.pack(fill=tk.BOTH, expand=True, padx=10, pady=10) # 控制面板 control_frame = tk.Frame(main_frame) control_frame.pack(side=tk.LEFT, fill=tk.Y, padx=5, pady=5) # 滤波器设置 filter_frame = tk.LabelFrame(control_frame, text="滤波器设置") filter_frame.pack(fill=tk.X, padx=5, pady=5) # 滤波器类型选择 tk.Label(filter_frame, text="滤波器类型:").grid(row=0, column=0, sticky=tk.W, padx=5, pady=5) self.filter_type = tk.StringVar(value="None") filter_types = ["None", "陷波滤波器", "IIR低通", "FIR低通"] filter_menu = tk.OptionMenu(filter_frame, self.filter_type, *filter_types) filter_menu.grid(row=0, column=1, sticky=tk.W, padx=5, pady=5) # 截止频率 tk.Label(filter_frame, text="截止频率 (Hz):").grid(row=1, column=0, sticky=tk.W, padx=5, pady=5) self.cutoff_freq = tk.DoubleVar(value=50) tk.Scale(filter_frame, from_=1, to=100, resolution=1, orient=tk.HORIZONTAL, variable=self.cutoff_freq).grid(row=1, column=1, sticky=tk.W, padx=5, pady=5) # 滤波器阶数 tk.Label(filter_frame, text="滤波器阶数:").grid(row=2, column=0, sticky=tk.W, padx=5, pady=5) self.filter_order = tk.IntVar(value=4) tk.Scale(filter_frame, from_=1, to=20, resolution=1, orient=tk.HORIZONTAL, variable=self.filter_order).grid(row=2, column=1, sticky=tk.W, padx=5, pady=5) # 应用滤波按钮 tk.Button(filter_frame, text="应用滤波", command=self.apply_filter).grid(row=3, column=0, columnspan=2, padx=5, pady=5, sticky=tk.EW) # 特征提取 feature_frame = tk.LabelFrame(control_frame, text="特征提取") feature_frame.pack(fill=tk.X, padx=5, pady=5) tk.Button(feature_frame, text="显示频谱", command=self.show_spectrum).pack(padx=5, pady=5, fill=tk.X) # 状态信息 self.status_label = tk.Label(control_frame, text="等待加载数据...") self.status_label.pack(padx=5, pady=5, fill=tk.X) # 心率显示 self.hr_label = tk.Label(control_frame, text="心率: -- bpm") self.hr_label.pack(padx=5, pady=5, fill=tk.X) # 数据信息 self.data_label = tk.Label(control_frame, text="未加载数据") self.data_label.pack(padx=5, pady=5, fill=tk.X) # 绘图区域 plot_frame = tk.Frame(main_frame) plot_frame.pack(side=tk.RIGHT, fill=tk.BOTH, expand=True, padx=5, pady=5) # 嵌入matplotlib画布 from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg from matplotlib.figure import Figure self.fig = Figure(figsize=(8, 6), dpi=100) self.ax = self.fig.add_subplot(111) self.canvas = FigureCanvasTkAgg(self.fig, master=plot_frame) self.canvas.get_tk_widget().pack(fill=tk.BOTH, expand=True) def load_data(self): # 选择文件 file_path = filedialog.askopenfilename( title="选择心电信号数据文件", filetypes=[("CSV文件", "*.csv"), ("所有文件", "*.*")], initialdir="c:\\Users\\32525\\Desktop\\code\\ecg\\实验八-资料\\心电信号处理实验" ) if file_path: try: # 读取数据 df = pd.read_csv(file_path, header=None) # 如果数据包含两列（索引和值），只取第二列 if df.shape[1] > 1: self.ecg_data = df.iloc[:, 1].values else: self.ecg_data = df.iloc[:, 0].values self.data_label.config(text=f"已加载: {len(self.ecg_data)} 个采样点") self.filtered_data = self.ecg_data.copy() self.plot_signal() except Exception as e: self.status_label.config(text=f"数据加载错误: {str(e)}") def apply_filter(self): if self.ecg_data is None: self.status_label.config(text="请先加载数据") return try: filter_type = self.filter_type.get() cutoff = self.cutoff_freq.get() order = self.filter_order.get() # 根据选择的滤波器类型应用滤波 if filter_type == "None": self.filtered_data = self.ecg_data.copy() elif filter_type == "陷波滤波器": # 50Hz陷波滤波器 b, a = signal.iirnotch(50, 30, self.fs) self.filtered_data = signal.filtfilt(b, a, self.ecg_data) elif filter_type == "IIR低通": # IIR Butterworth低通滤波器 b, a = signal.butter(order, cutoff, btype='low', fs=self.fs) self.filtered_data = signal.filtfilt(b, a, self.ecg_data) elif filter_type == "FIR低通": # FIR低通滤波器 b = signal.firwin(order + 1, cutoff, fs=self.fs, pass_zero='lowpass') self.filtered_data = signal.filtfilt(b, 1, self.ecg_data) self.status_label.config(text=f"已应用{filter_type}") self.plot_signal() except Exception as e: self.status_label.config(text=f"滤波错误: {str(e)}") def extract_qrs(self): if self.filtered_data is None: return [], 0 try: # 检测QRS波峰值 peaks, _ = signal.find_peaks(self.filtered_data, height=np.max(self.filtered_data)-200, distance=250) # 最小峰值间距(ms级) heart_rate = 0 if len(peaks) > 1: # 计算RR间期(秒) rr_intervals = np.diff(peaks) / self.fs # 计算心率(基于中位数) heart_rate = 60 / np.median(rr_intervals) return peaks, int(heart_rate) except Exception as e: self.status_label.config(text=f"QRS提取错误: {str(e)}") return [], 0 def plot_signal(self): if self.filtered_data is None: return try: self.ax.clear() # 生成时间轴 t = np.arange(len(self.filtered_data)) / self.fs # 绘制原始信号和滤波后信号 if hasattr(self, 'ecg_data') and self.ecg_data is not None: self.ax.plot(t, self.ecg_data, 'b-', alpha=0.5, label='原始信号') self.ax.plot(t, self.filtered_data, 'r-', label='滤波后信号') # 提取并标记QRS波 peaks, heart_rate = self.extract_qrs() if len(peaks) > 0: self.ax.plot(t[peaks], self.filtered_data[peaks], 'go', markersize=8, label='QRS波') self.hr_label.config(text=f"心率: {heart_rate} bpm") else: self.hr_label.config(text="心率: -- bpm") self.ax.set_title('心电信号波形') self.ax.set_xlabel('时间 (s)') self.ax.set_ylabel('幅值') self.ax.legend() self.ax.grid(True) self.fig.tight_layout() self.canvas.draw() except Exception as e: self.status_label.config(text=f"绘图错误: {str(e)}") def show_spectrum(self): if self.filtered_data is None: self.status_label.config(text="请先加载数据") return try: # 计算频谱 n = len(self.filtered_data) fft_result = np.fft.fft(self.filtered_data - np.mean(self.filtered_data)) freq = np.fft.fftfreq(n, 1/self.fs) amp = np.abs(fft_result) / np.max(np.abs(fft_result)) # 归一化 # 只显示正频率部分 pos_freq = freq[:n//2] pos_amp = amp[:n//2] # 绘制频谱 self.ax.clear() self.ax.plot(pos_freq, pos_amp, 'b-') self.ax.set_title('心电信号频谱') self.ax.set_xlabel('频率 (Hz)') self.ax.set_ylabel('归一化幅值') self.ax.set_xlim([0, 100]) # 只显示0-100Hz self.ax.grid(True) self.fig.tight_layout() self.canvas.draw() except Exception as e: self.status_label.config(text=f"频谱分析错误: {str(e)}") # 运行程序 if __name__ == "__main__": root = tk.Tk() app = ECGProcessingSystem(root) root.mainloop()

3.2.2 关键函数说明

  • signal.iirnotch()：设计50Hz陷波滤波器，去除工频干扰
  • signal.butter()：设计Butterworth IIR滤波器
  • signal.firwin()：设计FIR滤波器
  • signal.filtfilt()：实现零相位滤波，避免信号相位偏移
  • signal.find_peaks()：检测QRS波峰值
  • np.fft.fft()：进行快速傅里叶变换

4. 实验分析与讨论

4.1 滤波效果分析

通过实验对比不同滤波器的效果：

  • 陷波滤波器：能够有效去除50Hz工频干扰，对于存在明显电源干扰的信号效果显著。
  • IIR低通滤波器：采用4阶Butterworth滤波器，截止频率50Hz时，能够有效滤除高频噪声，同时保持QRS波的完整性。但高阶IIR滤波器可能会引入一定的相位失真。
  • FIR低通滤波器：采用5阶FIR滤波器，具有线性相位特性，滤波后的信号相位保持不变，适合对相位敏感的应用场景。

4.2 QRS波检测性能

实验中采用基于峰值检测的方法，通过设置合适的阈值参数（峰值高度和间距），成功检测到心电信号中的QRS波群。在6144个采样点的数据中，共检测到12个QRS波，计算得到的心率为60 bpm，与实际情况相符。

4.3 系统性能评估

  • 实时性：系统采用高效的滤波算法和绘图技术，能够实现实时数据处理和可视化。
  • 用户体验：提供直观的交互式界面，用户可以方便地调整滤波器参数，实时观察处理效果。
  • 稳定性：系统具备完善的错误处理机制，能够处理异常情况，保证稳定运行。

4.4 存在的问题与改进方向

  • 噪声适应性：当前系统对强噪声环境下的信号处理能力有限，未来可以考虑采用自适应滤波算法。
  • QRS波检测准确性：对于低质量心电信号，QRS波检测可能会出现误检或漏检，需要进一步优化检测算法。
  • 功能扩展：可以增加更多的心电特征提取功能，如P波和T波检测，ST段分析等。
  • 界面优化：可以进一步优化界面布局，增加更多的数据可视化方式。

4.5 实验结论

本实验成功设计并实现了一个功能完整的交互式心电信号处理系统，能够完成心电信号的加载、滤波处理、时频域分析和QRS波提取等功能。系统采用模块化设计，界面友好，操作便捷，具有良好的实时性和稳定性。实验结果表明，系统能够有效去除心电信号中的噪声干扰，准确提取QRS波特征，为心电信号的分析和诊断提供了有力的工具。
