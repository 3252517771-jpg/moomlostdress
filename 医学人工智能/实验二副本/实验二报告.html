三、实验内容和要求

1. 遗传算法的基本原理

遗传算法是一类借鉴生物界自然选择和自然遗传机制的随机搜索算法，非常适用于处理传统搜索方法难以解决的复杂和非线性优化问题。在求解问题时从多个解开始，然后通过一定的法则进行逐步迭代以产生新的解。遗传算法的基本流程包括：初始化种群、适应度评价、选择、交叉、变异和终止判断。

2. 目标函数

本实验优化的目标函数为：

F(x1, x2) = x12/4000 + x22/4000 - cos(x1)·cos(x2/√2) + 1

其中 |x1| ≤ 10，|x2| ≤ 10。该目标函数的最优值为 Fmin(0, 0) = 0，属于多峰函数，在搜索空间内存在多个局部最优解。

3. 核心遗传操作

3.1 染色体编码与解码

采用二进制编码，每个实数变量用20位二进制串表示，两个变量共40位。初始化种群为随机生成的0/1矩阵。解码时由二进制转换为十进制，并映射到[-10, 10]区间：

def decode(x, a, b):
    xt = 0
    for i in range(len(x)):
        xt = xt + x[i] * np.power(2, i)
    return a + xt * (b - a) / (np.power(2, len(x)) - 1)

3.2 轮盘赌选择

各个个体的选择概率和其适应度成比例，适应度越大，被选中概率越大。利用numpy的random.choice函数实现：

def select(pop, f_values):
    fitness = 1 / (f_values + 1e-8)
    fitness = fitness / fitness.sum()
    idx = np.array(list(range(pop.shape[0])))
    selected_idx = np.random.choice(idx, size=POP_SIZE, p=fitness)
    return pop[selected_idx, :]

3.3 交叉与变异

交叉操作采用均匀交叉方式，随机生成交叉点，以一定概率交换父代染色体片段。变异操作按位进行，以变异率随机翻转某些基因位。

1. 实验体会

通过本次实验，我对遗传算法的基本原理和实现过程有了深入的理解。遗传算法通过模拟自然选择和遗传机制，能够在复杂的搜索空间中进行高效的全局优化。实验中，我深刻体会到编码方式、选择策略、交叉和变异操作对算法性能的关键影响。特别是面对多峰函数时，遗传算法的群体搜索特性使其具有比传统梯度下降方法更强的全局寻优能力。

在参数调优方面，我认识到种群数量、交叉率和变异率三者之间存在密切的相互制约关系。种群数量决定了搜索的广度，交叉率影响信息的交换效率，变异率则维持种群的多样性。三者需要协同调整，才能使算法在探索和开发之间取得平衡。

2. 实验过程中遇到的问题及解决方法

问题一：遗传算法陷入局部最优，部分运行未收敛到全局最优。

解决方法：这是由于本实验采用的基本遗传算法未引入精英保留策略，且目标函数为多峰函数，容易陷入局部最优。为了获得稳定可靠的实验结果，我采用了多次独立运行（5次）取最优的策略，有效降低了随机性的影响，使实验结论更加可信。

问题二：Matplotlib绘制对数坐标曲线时出现Unicode减号（U+2212）显示警告，图片中负号显示为方块。

解决方法：该问题是由于Matplotlib默认的对数刻度格式化器（LogFormatter）使用了Unicode减号，而当前字体不支持该字符。我通过自定义ticker.FuncFormatter，使用Python原生格式化字符串（f-string）替代默认格式化器，确保生成的减号为ASCII字符，从而彻底解决了该显示问题。

问题三：三维图绘制时出现FixedFormatter警告。

解决方法：在使用set_xticklabels手动设置刻度标签时，需要先通过set_xticks设置对应的刻度位置，否则Matplotlib会发出FixedFormatter警告。修改为先设置刻度位置再设置刻度标签后，警告消除。

3. 实验结论

本次实验成功实现了遗传算法求解多峰函数优化问题，并通过三组对照实验系统分析了种群数量、交叉率和变异率对算法性能的影响。实验结果符合遗传算法的基本理论：增大种群数量有利于加快收敛；交叉率应保持适中，过高会破坏优良模式；变异率需要平衡多样性和稳定性。这些结论为后续在实际问题中应用遗传算法提供了重要的参数选择依据。
