摘  要

本报告介绍了模拟退火算法的基本原理与实现方法。该算法源于固体退火过程，通过引入温度参数和概率接受机制，能够有效避免陷入局部最优解，成功应用于函数优化问题。实验表明，调整初始温度、冷却率和马尔科夫链长度等参数可显著影响算法性能。

关键词：

模拟退火算法；全局优化； Metropolis准则；马尔科夫链；函数优化

一、引言

在工程实践和科学研究中，优化问题无处不在。传统的梯度下降法虽然收敛速度快，但容易陷入局部最优解，难以获得全局最优解。模拟退火算法（Simulated Annealing，SA）作为一种全局优化算法，通过模拟固体退火过程，能够在解空间中有效跳出局部最优，寻找全局最优解或近似全局最优解。

本报告基于目标函数 f(x) = x + 10sin(3x) + cos(x) 在区间 [0, 9] 上的最小值搜索问题，详细阐述模拟退火算法的原理、流程、参数影响及其应用。

二、模拟退火算法原理

（一）算法起源

模拟退火算法最早由Kirkpatrick等人于1983年提出，其核心思想来源于金属退火过程。当金属被加热至高温后，其内部粒子处于高速无序状态；随后缓慢降温，粒子逐渐趋于有序，最终在常温下达到能量最低的稳定状态。模拟退火算法正是将这一物理过程抽象为数学优化方法。

（二）Metropolis准则

Metropolis准则 是模拟退火算法的核心接受准则。在某一温度 T 下，假设当前解为 x，对应的目标函数值为 E(x)。通过扰动产生新解 x'，目标函数值为 E(x')。则接受新解的概率为：

P = min(1, exp(-(E(x') - E(x)) / kT))

其中，k 为玻尔兹曼常数。当 E(x') < E(x) 时，新解被无条件接受；当 E(x') ≥ E(x) 时，以概率 exp(-ΔE/T) 接受新解。这种机制使得算法在高温下能够概率性地接受较差的解，从而跳出局部最优。

（三）温度更新机制

温度的缓慢下降是模拟退火算法收敛到全局最优解的关键。常用的温度更新策略包括：

（1）线性降温：Tk+1 = Tk - α，其中 α 为常数；

（2）比例降温：Tk+1 = λ × Tk，其中 λ ∈ (0, 1) 为冷却率；

（3）对数降温：Tk = c / log(k + 1)，其中 c 为常数。

本实验采用比例降温策略，因其实现简单且效果良好。

三、算法流程

（一）算法步骤

模拟退火算法的基本流程如下：

Step 1：初始化。设定初始温度 T、冷却率 α、最小温度 Tmin、马尔科夫链长度 L，随机产生初始解 x。

Step 2：在当前温度 T 下，循环执行以下操作 L 次（马尔科夫链）：

    （1）产生新解 x' = x + Δx，其中 Δx 为邻域扰动；

    （2）计算目标函数差值 ΔE = f(x') - f(x)；

    （3）若 ΔE < 0，则接受新解 x = x'；否则以概率 exp(-ΔE/T) 接受新解；

    （4）更新最优解。

Step 3：按照 T = α × T 更新温度。

Step 4：若 T > Tmin 且未达到最大迭代次数，则转向 Step 2；否则输出最优解。

四、参数对算法性能的影响

（一）初始温度的影响

初始温度 T₀ 决定了算法初期的全局搜索能力：

（1）较高的初始温度（如 5000~10000）：高温下算法能以较大概率接受较差的解，有效跳出局部最优陷阱，但会增加搜索时间；

（2）较低的初始温度（如 100~500）：搜索速度快，但可能过早收敛至局部最优解；

（3）推荐范围为 1000~10000，本实验选择 5000。

（二）马尔科夫链长度的影响

马尔科夫链长度 L 表示每个温度下进行的搜索次数：

（1）较长的链（如 30~50）：在每个温度下进行更充分的邻域搜索，能更精细地探索解空间，但耗时显著增加；

（2）较短的链（如 5~10）：搜索速度快，但可能错过更优的邻域解；

（3）推荐范围为 10~50，本实验选择 10。

（三）冷却率的影响

冷却率 α 控制温度下降的速度：

（1）较慢的冷却（如 α = 0.99）：温度下降缓慢，搜索精细，能更好地逼近全局最优，但计算时间较长；

（2）较快的冷却（如 α = 0.5~0.8）：温度下降快，搜索速度快，但容易跳过全局最优区域；

（3）推荐范围为 0.9~0.999，本实验选择 0.99。

五、算法优缺点分析

（一）算法优点

（1）全局搜索能力强：通过概率接受机制，算法能够跳出局部最优，向全局最优方向搜索；

（2）算法框架通用：对目标函数的数学性质（如连续性、可导性）要求不高，适应范围广；

（3）参数设置相对灵活：初始温度、冷却率、马尔科夫链长度等参数可根据具体问题调整；

（4）易于与其他算法结合：可作为局部搜索算子或与遗传算法、粒子群算法等混合使用。

（二）算法缺点

（1）收敛速度较慢：为确保收敛到全局最优，需要缓慢降温并接受较差的解，导致搜索时间长；

（2）参数敏感：初始温度、冷却率等参数对算法性能影响显著，需要精心调参；

（3）近似最优解而非精确解：算法输出的是全局最优解的近似，精度与参数设置和计算时间相关；

（4）难以判断收敛性：缺乏有效的收敛判据，通常依靠最大迭代次数或最小温度终止。

七、结论

本报告详细介绍了模拟退火算法的基本原理、算法流程、参数影响及其应用。实验证明，通过合理设置初始温度、冷却率和马尔科夫链长度等参数，模拟退火算法能够有效避免局部最优，找到全局最优解或近似全局最优解。尽管该算法存在收敛速度较慢的缺点，但其全局搜索能力和广泛的适用性使其成为解决复杂优化问题的重要工具。
