# 遗传算法求解目标函数

## 项目说明

本项目使用遗传算法（Genetic Algorithm, GA）求解以下目标函数的最小值：

```
y = x² + 10·cos(2πx) + 10
```

**理论最优解：** x = 0, y = 1（全局最小值）

## 遗传算法原理

### 核心步骤：

1. **初始化种群** - 随机生成二进制染色体
2. **解码** - 将二进制编码转换为实数值
3. **计算适应度** - 评估每个个体的优劣
4. **选择** - 轮盘赌选择法保留优良个体
5. **交叉** - 单点交叉产生新个体
6. **变异** - 位点变异增加多样性
7. **迭代** - 重复步骤2-6直到达到最大代数

### 关键参数说明：

- **种群数量（pop_size）：** 
  - 越大：搜索结果更稳定，但计算时间长
  - 越小：计算快，但可能陷入局部最优

- **交叉率（crossover_rate）：**
  - 过高（>0.9）：可能破坏优良基因，早熟收敛
  - 过低（<0.5）：搜索速度慢，进化效率低
  - 推荐：0.7-0.9

- **变异率（mutation_rate）：**
  - 过高（>0.05）：随机搜索，难以收敛
  - 过低（<0.001）：容易陷入局部最优
  - 推荐：0.001-0.01

## 注意事项

1. 由于遗传算法的随机性，每次运行结果可能略有不同
2. 可以通过修改代码中的参数来探索不同的配置
3. 建议多次运行取平均值以获得更可靠的结果
4. 生成的图片文件会保存在当前目录下

## 扩展建议

1. **调整搜索范围：** 修改 `x_range` 参数
2. **改变编码方式：** 可以尝试实数编码代替二进制编码
3. **改进选择策略：** 可以尝试锦标赛选择、排名选择等
4. **自适应参数：** 实现交叉率和变异率的自适应调整
5. **精英保留策略：** 保留每一代的最优个体不参与交叉变异
