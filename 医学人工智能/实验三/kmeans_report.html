摘要
本实验通过K-means聚类算法对心电数据进行聚类分析，手动实现了兰德指数(RI)和调整兰德系数(ARI)指标计算，验证了初始中心敏感性和K值选择对聚类效果的影响，并展示了K-means算法在非球状和密度不均匀数据上的失效案例。实验结果表明，K-means算法在球状分布数据上表现良好，但对初始中心和K值敏感，且无法有效处理非凸形状和密度不均匀的数据。

二、实验原理
2.1 K-means聚类算法
K-means是一种基于距离的无监督聚类算法，核心思想是将n个数据点划分为K个簇，使得每个簇内的数据点到簇中心的距离平方和最小。算法步骤为：（1）随机选择K个初始中心；（2）计算每个数据点到各中心的距离，将其分配到最近的簇；（3）更新每个簇的中心为该簇所有数据点的均值；（4）重复步骤（2）（3）直到收敛或达到最大迭代次数。
2.2 聚类评估指标
兰德指数（RI）：衡量聚类结果与真实标签的一致性，取值范围[0,1]，计算公式为：
RI = (a + d) / (a + b + c + d)
其中，a为同类同簇对数，b为同类不同簇对数，c为不同类同簇对数，d为不同类不同簇对数。
调整兰德系数（ARI）：对RI进行校正，考虑随机聚类的影响，取值范围[-1,1]，计算公式为：
ARI = (RI - E[RI]) / (max(RI) - E[RI])

3.6 任务5：非球状数据K-means失效案例
生成非球状分布的数据集（环形分布），使用K=3进行聚类，结果如图5所示。
图5 非球状数据K-means聚类失效示例（环形数据被错误划分）
聚类指标：RI = 0.7765，ARI = 0.5050。
失效原因分析：K-means算法假设数据是球状分布的，对于环形等非凸形状的数据，算法会强制将数据划分到最近的簇中心，导致同一簇被分割或不同簇被合并。
3.7 任务6：密度不均匀数据K-means失效案例
生成密度不均匀的数据集（一个大簇包含一个小而密集的簇），使用K=3进行聚类，结果如图6所示。
图6 密度不均匀数据K-means聚类失效示例（小簇被大簇吸收）
聚类指标：RI = 0.5934，ARI = 0.2420。
失效原因分析：K-means使用欧氏距离计算，会偏向于将中心吸引到密集区域。对于密度不均匀的数据，小而密集的簇可能被忽略或合并到邻近的大簇中。
四、实验结果分析与问题解答
4.1 初始中心对聚类结果的影响
初始中心的选择对K-means聚类结果有一定影响，但在本实验中（使用K-means++初始化），两次运行的ARI差异仅为0.0097，表明算法具有较好的稳定性。这是因为K-means++算法通过智能选择初始中心，能够避免陷入较差的局部最优解。
4.2 K值选择对聚类结果的影响
K值是K-means算法最重要的超参数。当K值小于真实簇数时，会发生过度合并，导致聚类效果下降；当K值等于真实簇数时，聚类效果最佳；当K值大于真实簇数时，会发生过度分割，同样导致效果下降。选择最佳K值的常用方法包括肘部法则、轮廓系数和Gap统计量。
4.3 K-means算法的失效原因分析
非球状数据失效原因：K-means算法基于欧氏距离，假设簇是凸的、球状的。对于环形、月牙形等非凸分布，算法无法正确捕捉数据的内在结构。
密度不均匀数据失效原因：K-means算法的目标是最小化簇内误差平方和，这会使簇中心偏向于密集区域。当数据密度不均匀时，小而密集的簇可能被邻近的大簇吸收。
五、实验小结
5.1 实验体会
通过本次实验，我深入理解了K-means聚类算法的原理和实现过程，掌握了聚类结果的评估方法。实验表明，K-means算法在处理球状分布数据时表现优秀，但存在对初始中心敏感、需要预先指定K值、无法处理非凸形状和密度不均匀数据等局限性。
5.2 遇到的问题及解决方法
问题1：ARI指标计算错误。最初实现的ARI公式有误，导致计算结果超出[-1,1]范围。解决方法：对照标准公式重新实现，确保公式中的统计量定义正确，并与sklearn库的结果进行对比验证。
问题2：密度不均匀数据失效案例不明显。最初生成的数据未能有效展示K-means的失效。解决方法：调整数据生成参数，将小簇嵌入大簇内部，使用单次初始化，成功展示了算法在密度不均匀数据上的失效情况。
问题3：中文图表乱码。Matplotlib默认不支持中文显示。解决方法：设置font.sans-serif为中文字体（如SimHei、Microsoft YaHei），并关闭负号显示问题。
5.3 改进方向
（1）使用K-means++进行智能初始化，提高算法稳定性
（2）使用肘部法则或轮廓系数自动选择最佳K值
（3）对高维数据先进行PCA降维，再进行聚类
（4）对于非凸数据，使用密度聚类（DBSCAN）或谱聚类
（5）使用核K-means处理复杂形状的数据
